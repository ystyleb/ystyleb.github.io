Find a comfortable gap between comparison tiles

Use the same three synthetic image tiles to look for a gap that keeps comparisons readable. Cut the preview width first, then change the gap. Check whether the images still keep enough room for their content.

Check it on the actual export

  1. Start from the narrowest screen or smallest attachment you expect a reviewer to use.
  2. Ensure the gap separates subjects that would otherwise look like one image. Leave enough room for a label and its nearest feature.
  3. Switch to a two-column or vertical layout when squeezing all images onto one row hides the evidence.
