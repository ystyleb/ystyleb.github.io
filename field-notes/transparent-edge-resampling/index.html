See what resampling does to very small artwork

Resize the same drawn mark twice. This tool shows a nearest-neighbor sample and a smoothed sample, enlarged so you can compare the pixel edges. The check uses an original test mark generated in your browser.

Use the comparison when exporting

  1. Check both results at the actual destination size before inspecting the enlarged pixels.
  2. For pixel art, inspect uneven line thickness after shrinking. For illustrated edges, look for lost fine details and test over light and dark backgrounds.
  3. In a comparison panel, re-export from the original size if a tiny raster tile has already lost the texture you want to inspect.

This is a browser exercise. Browser smoothing details can differ, and repeated resizing, compression or transparency processing may change a real export.
