Separate thinking time from typing time

When a timed open-answer game is hard on a phone, check whether players need more time to think or more time to enter an answer. Try this untimed worksheet first. It records a duration in this tab and clears the text when the round ends.

Choose Start when ready.

Do a fair comparison

  1. Use a practice prompt to learn the controls. For a real test, prepare several prompts of similar difficulty. Switch which device gets which prompt so prior exposure does not help just one device.
  2. Press “I have an answer” before typing anything. Then enter the answer at a comfortable speed. Record times per player and compare their own device pairs.
  3. When entry is slower, test the input field, keyboard activity and submit affordance before changing the game’s clock. If thinking takes longer, have the player describe their interpretation of the prompt.

This worksheet does not judge an answer. The split includes button and focus overhead. Avoid interpreting a single pass as a timing limit or as feedback about the player’s ability.
