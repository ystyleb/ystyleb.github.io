How many prompts did your test group actually cover?

When you test a deck of word prompts, a long session can still leave cards untouched. Paste the number of times you tried each card, including zero for cards nobody drew. The worksheet separates coverage from repeated plays.

Try the worksheet

Read the result

  1. Give each prompt a stable number before anyone plays. If you add a card mid-test, add another zero at the end of the list.
  2. In the sample, ten plays covered only four of seven cards. That leaves cards 2, 5 and 7 to test deliberately in the next session.
  3. Coverage says which prompts received attention. Write down ambiguous answers or awkward phrasing separately so a heavily played card can still be revised.
