Measure how often a practice prompt produces the same answer

Collect one independent answer per player before anyone hears another response. Paste one response per line to find what share of player pairs gave an identical answer. This is a rehearsal measure for the host.

Try it

Use the result

  1. Test a prompt on a small group. Keep repeated answers on separate lines because each line represents a different person.
  2. For the five sample lines there are ten distinct pairs of players. Three pairs match on pear, giving 30%. A second prompt with the same group gives you a comparison with the same sample size.
  3. Capitalization and repeated spaces are ignored. Decide before recording whether synonyms should be equivalent; if so, enter your agreed spelling for each. Small groups give a rough estimate, and this worksheet does not reproduce a game’s scoring engine.
