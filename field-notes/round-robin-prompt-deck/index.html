Rotate a prompt deck across tables

Plan a word-game night with several tables and printed prompt packs. Each round, pass packs a fixed number of tables clockwise. Find out whether a pack will visit every table before returning to its starting point.

Try it on paper

With six tables and a jump of two, the pack that starts at table 1 visits 3 and 5 and returns. Half the room never sees it. Set the jump to one and the same pack reaches all six.

Mark the pack with its start number and stop before the first repeat. One person records a rare answer, another reads the prompt, and the roles switch on each pass. Use invented prompts so everyone begins with the same information.

Where to try it

  • Streakdle — Practice the rare-answer format in an unlimited round before taking it to the tables. The table rotation is a separate paper activity.
