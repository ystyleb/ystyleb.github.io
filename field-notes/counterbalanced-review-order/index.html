Give two review samples a fair first impression

When all reviewers see sample A first, the first position can change the score. Use the same instructions for both sequences and alternate which sample comes first. This worksheet builds a small copyable assignment list.

Prepare each session

  1. Assign each reviewer a neutral number. Label the sample headings A and B in a private key.
  2. Keep review timing, prompts and device conditions comparable. After the first sample, mark its score before opening the second.
  3. With an odd count, one order has an extra reviewer. Write down how many saw each order and check whether comments cluster by order.

For interaction or puzzle tests, avoid showing the same answer twice. Use distinct examples with comparable difficulty or run a fresh group for each option. This simple ordering worksheet does not account for differences between reviewers.
