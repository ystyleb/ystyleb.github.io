Compare skipped answers in a timed playtest

One skipped answer in five plays and twenty skips in a hundred are both 20%. The first result leaves much more uncertainty about what another group will do.

Use two independent groups with the same time limit, display and scoring rules. Count one attempt per player in each group. Define a skip before running the test. A blank response at the deadline might count as a skip; a disconnected player should be logged separately.

Each line shows the observed rate and a 95% Wilson interval for its own group. Treat the bounds as uncertainty around that group's estimate. Overlap alone cannot tell you whether the prompts differ, and the interval does not fix a biased recruiting sample. See the NIST formula for the calculation.

Run a follow-up

  1. Ask players who skipped whether the category was unclear or whether they could not think of an answer.
  2. Change only one thing, such as replacing an ambiguous family of words with a concrete example. Run the old and new versions in the same session with randomly assigned groups.
  3. Report attempts, skips and disconnects together. With repeated attempts from the same players, summarize results per player or use a method that accounts for repeated observations.
