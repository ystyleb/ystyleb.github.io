Measure how much your puzzle prompt gives away

A moderator can inadvertently coach a player by naming the topic in the introduction. Compare two small groups on the same opening puzzle. Give one group a short, neutral prompt and the other the planned introduction. Use each participant’s first exposure.

Independent first-time testers

Keep the groups comparable

  1. Use the same opening puzzle, device type and limit for both groups. If a site serves different questions, record the visible round and use the worksheet only for matched prompts.
  2. Write exact wording and count a success only if completed before the moderator says anything beyond the prompt.
  3. Capture what the player thought the rules were. A different solve rate can reflect clearer rules, an accidental hint or simple sampling variation. Read the notes before changing the copy.

The counts shown are fictional. With small groups, report raw counts alongside percentages and treat the difference as a signal to investigate.
