Test translated copy at its real display width

Compare the source and proposed translation inside identical boxes. Use the input width of an actual overlay, caption or control. This browser measurement helps identify where text wraps; it does not validate a translation.

Try different kinds of copy

  • For artwork, localize interface text beside images and keep labels legible at export size.
  • For audio and video, measure captions in the real player. Keep approved names intact.
  • For browsers games, try long prompt words and a narrow device. Confirm the timer and action labels remain visible.

Font, writing direction and line breaking can vary. Test the final device and language.
